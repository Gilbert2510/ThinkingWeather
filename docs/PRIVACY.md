# 随想天气隐私说明（发布前请补全运营者和联系渠道）

应用为用户主动选择的城市获取天气，无需账户，不读取通讯录、电话、媒体或外部存储，不包含广告或分析 SDK。

## 位置信息

只有点击“使用当前位置”时才申请 Android 大致位置权限。位置用于城市反向查询，请求坐标保留两位小数，不在后台持续获取。拒绝后仍可手动搜索城市；应用不将设备标识与位置绑定。

最后解析到的已保存城市身份用于位置标记，不另存原始传感器坐标或位置历史；删除该城会清除标记。若无法解析为城市，近似坐标可能作为“当前位置”这一收藏的身份和天气查询坐标保存。定位提示约 3 秒后收起，不代表删除收藏或缓存。

## 公网服务

1.1.0 起，手机和模拟器均经阿里云 FC 公网 HTTPS 代理访问和风天气，不再连接开发电脑或使用 USB 转发，也不申请本地网络权限。公开代理会收到城市查询、坐标或查询文本与网络连接 IP，和风服务会收到天气查询。

API Key 与开发者专属 API Host 仅由阿里云函数环境变量持有；APK 不包含这些凭据。运行链路与部署者必须按实际情况补充 FC、API 网关、WAF 和日志服务的保留期限及删除渠道。仓库提供的替换函数不记录请求/响应全文或环境变量，但仓库修改不会自动改变控制台现有代码或平台日志设置。

城市搜索在独立页面进行。国内/国际热门目录随应用提供，打开或切换目录本身不发送查询，点击选择后才请求该城天气。区县显示名补全使用本地行政名称资源，不向新增第三方地理服务发送查询。

城市页在前台为已保存城市补齐当前天气摘要；离开页面或进入后台会取消这组更新。详情和图表使用已取得快照，不重复获取整套数据。生活指数随完整天气查询获取，仅传同一城市或近似坐标，无权限/覆盖时不编造建议。

设置 → 关于展示提供方、已提供的数据来源与许可，外部 HTTPS 链接仅在点击后打开。

## 官方天气地图

仅在用户点击主页地图按钮后，在独立页面通过系统 WebView 浏览 `https://map.qweather.com/`。这是和风维护的第三方网页，会向和风及其网页资源/CDN 服务发送正常浏览请求，服务方可收到 IP、浏览器信息及网页内主动操作；其数据处理适用官方政策。打开主页本身不加载地图。

地图页未加入任何和风 Key、原生 JavaScript 桥或坐标参数，不将 App 定位结果传给网页，且拒绝网页定位权限。地图的图层、图例、时效与功能以官方网站为准。为运行交互地图启用 JavaScript 和 DOM 存储；页面可在应用私有 WebView 存储中保存第一方站点数据和缓存，第三方 Cookie 被禁用。清除应用数据或卸载可删除本地站点数据；退出页面停止加载并销毁 WebView。用户可选择用系统浏览器打开，之后遵循浏览器自身的数据设置。

## 网络提示

使用普通 `ACCESS_NETWORK_STATE` 权限在前台识别默认网络和移动流量，短暂显示“请注意，当前正在使用移动流量”或“当前未连接网络”。移动流量提示在此安装中只显示一次，已显示标记仅保存在本机，重新进入前台或重启进程不会重复；清除数据或重装后重置。不读取账单、SIM 身份或网络名称，不上传网络状态；离开前台注销监听。无互联网路由或需要登录的网络提前提示不可用；系统通用互联网验证未通过时，仍允许尝试已配置的 HTTPS 天气服务，以实际请求结果处理失败，不另向第三方发送连通性探测。

## 本地保存

收藏及顺序、当前选择、最后定位城市标记、温度单位、最近完整天气和最多 30 条天气摘要保存在应用私有目录；摘要与完整天气分别保存。删除收藏会移除该城的摘要和位置标记，完整快照仍可能保留在有界缓存中。至少保留一座城市；清除应用数据或卸载可删除全部私有数据，系统备份已关闭。

旧示例模式偏好在升级后被忽略，示例缓存不作为真实天气使用；真实服务失败时只显示错误与已有真实缓存。App 已移除示例预览。用于质量验证的自动化测试夹具不会打入正式 APK，也不属于面向用户的运行页面。

## 发布者需补充

正式分发前补齐运营者名称、联系邮箱、政策生效日期与公开政策链接，并按实际云端配置说明日志、数据保留与删除方式。若后续加入账户、推送、原生地图 SDK 或统计，应同步政策并实现必要的同意和删除流程。
